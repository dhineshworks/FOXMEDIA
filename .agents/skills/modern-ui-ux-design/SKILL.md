# Modern UI/UX Design System Guide

## When to Use
- Designing cohesive, high-conversion user interfaces and design systems.
- Selecting harmonious color palettes, typography scales, and component tokens.
- Auditing visual hierarchy, contrast ratios, and user interaction states.

## Core Pillars
1. **Curated Color Theory:**
   - Avoid raw primary colors. Use tailored HSL / OKLCH scales with rich background undertones (e.g. Zinc-950 `#09090b` with warm orange/amber highlights).
   - Reserve high-chroma accent colors for primary CTAs and status indicators.
2. **Typography Hierarchy:**
   - Establish clear font-weight and size contrasts: Headlines (Bold/Extrabold, tight tracking `-0.025em`), Body (Regular/Medium, relaxed leading `1.6`), Overlines (Uppercase, semibold, wide tracking `0.1em`).
3. **Interactive States:**
   - Every clickable element must have distinct default, hover, active, focus-visible, and disabled states.
4. **Visual Scannability:**
   - Use badge chips, icon pairings, and clear tabular layout structures to reduce cognitive load.
